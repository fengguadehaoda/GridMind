# 监控面板说明

实时监控页（`/monitor`）用于 **电网设备运行状态总览**，包含健康评分、遥测趋势与异常检测。

## 1. 页面结构

- 顶部统计卡：设备总数 / 正常运行 / 预警 / 严重；
- 设备总览表：按健康分升序（最差在前）；
- 设备详情抽屉：基本信息、健康评分、遥测趋势、巡检记录。

## 2. 健康评分

健康分（0-100）由多维度遥测 + 异常检测聚合：

| 分数区间 | 等级 | 颜色 |
|---|---|---|
| ≥ 80 | 正常 | 绿 |
| 60-79 | 预警 | 黄 |
| < 60 | 严重 | 红 |

## 3. 遥测趋势

详情抽屉内的遥测图支持 `6h / 24h / 48h` 切换。

- 悬浮显示十字线与数据点；
- **异常越界点**（\|z-score\| > 2）以三角标记 + 红色描边提示。

## 4. Auto-grid 自适应

图表卡片采用 CSS Grid `auto-fit + minmax` 自动换列：

- 4K / 大屏：自动铺满 4 列；
- 2K：3-4 列；
- 1080p：2-3 列；
- 紧凑断点（1024-1280）：单列 / 双列。

> 布局变化通过 ResizeObserver + 300ms 防抖触发重绘，避免图表卡顿。

## 5. 空数据

- 无设备数据时表格显示空态；
- 无遥测数据时图表显示「暂无遥测数据」；
- 空数据面板自动隐藏，减少视觉噪音。

## 6. 常见问题

**Q：数据刷新失败？** 顶部工具栏会显示红色提示并自动重试，可点击「手动刷新」。
**Q：如何暂停自动刷新？** 关闭工具栏右侧「自动刷新」开关。
