# 快捷键总表

本页与「快捷键速查浮层」（任意页面按 `?`）内容同源。

## 1. 全局快捷键

| 快捷键 | 功能 |
|---|---|
| `⌘K` / `Ctrl+K` | 打开 / 关闭命令面板 |
| `?` | 打开快捷键速查浮层 |
| `ESC` | 关闭浮层 / 面板 / 抽屉（按优先级仲裁） |

> Mac 使用 `⌘`，Windows / Linux 使用 `Ctrl`。

## 2. 命令面板内

| 按键 | 功能 |
|---|---|
| `↑` / `↓` | 在结果列表中选择上 / 下一条 |
| `Enter` | 执行选中的命令 |
| `ESC` | 关闭面板 |

## 3. 路由直达

| 快捷键 | 目标路由 |
|---|---|
| `Ctrl+Shift+1` / `⌘+Shift+1` | 实时监控 `/monitor` |
| `Ctrl+Shift+2` / `⌘+Shift+2` | 灰度面板 `/grayscale` |
| `Ctrl+Shift+3` / `⌘+Shift+3` | HITL 审计 `/audit` |
| `Ctrl+Shift+4` / `⌘+Shift+4` | 系统总览 `/system` |
| `Ctrl+Shift+5` / `⌘+Shift+5` | 智能对话 `/` |

> 路由直达：Windows / Linux 使用 `Ctrl+Shift+数字`；Mac 使用 `⌘+Shift+数字`（行为一致）。`Ctrl+数字` 与 `Alt+数字` 均可能被浏览器切标签页占用、页面收不到事件；`Ctrl+Shift` / `⌘+Shift` 组合主流浏览器无默认行为。

## 4. 命令面板示例

```text
输入 "监控" 或 "jk" 或 "monitor" → 命中「实时监控」
输入 "新建" 或 "xj"          → 命中「新建对话」
```

## 5. 速查浮层使用

- 任意页面按 `?` 唤起；
- 焦点在输入框内时 `?` 不拦截（避免误触）；
- `ESC` 或点击遮罩关闭。
