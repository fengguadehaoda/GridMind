# PRD · GridMind 顶部 Header UI 重构

> 文档版本：v1.0 · 2026-08-06
> 产品负责人：许清楚（GridMind 产品经理）
> 关联需求：顶部 Header 信息过载（品牌 / 5 路由 / 三点菜单 / 连接状态 / CPU·内存·AIT·CLK / 3 状态徽标 / 7+ 按钮），用户反馈「按钮太过于密集，希望做成分类菜单，系统状态和时间换到其他地方，不占据顶部菜单栏的有限空间」
> 已确认设计决策：
> - 系统状态 + 时间 → 移到**右下角浮动小卡片**（类似 IDE / VS Code 状态条，固定右下角、可点击展开详情）
> - 顶部按钮收纳 → 做成**右侧抽屉（Drawer）**，从右侧滑出，按「视图 / 主题 / 系统 / 调试」分组
> - 复用现有组件（HitlBadge / SessionBadge / BackgroundModeToggle / ThemeToggle / CommandPalette 等），**不重建**

---

## 1. 产品目标

**一句话目标**：将顶部 Header 从「信息过载的工具栏」重构为「极简导航 + 分类收纳」，把系统状态与时间下沉到右下角浮动卡片，让调度员与运维工程师能 3 秒内定位任一入口，且不占用顶部菜单栏的有限空间。

**可衡量的验收标准**：

1. 顶部 Header 首屏元素数从现状 **~15 个减至 ≤5 个**：Logo / 主导航（5 路由）/ 单一「菜单」按钮 / 连接状态徽标 / 帮助图标。
2. 系统状态与时间（CPU / 内存 / AIT / CLK）**不再出现在顶部 Header**，全部迁移至右下角浮动卡片。
3. 通过右侧抽屉可访问 **100% 原入口**（视图 / 主题 / 系统 / 调试分组全部可见，无功能丢失）。
4. 抽屉内任一功能入口 **≤2 次点击**可达（打开抽屉 → 点击分组项）。
5. 现有组件（HitlBadge / SessionBadge / BackgroundModeToggle / ThemeToggle / CommandPalette 等）**全部复用**，不新建重复组件。

---

## 2. 用户故事

- **作为调度员**：我希望顶部只保留 Logo、导航、菜单按钮和连接状态，以便值班时快速在监控 / 灰度 / 审计 / 系统间切换，不被 CPU / 内存 / 时间等状态信息干扰视线。
- **作为调度员**：我希望低频入口（调试空间、主题切换、设置、RUNSPACE 等）收纳进右侧抽屉的分类菜单，以便需要时按「视图 / 主题 / 系统 / 调试」快速找到，不用记忆一排按钮的位置。
- **作为运维工程师**：我希望系统状态（CPU / 内存 / AIT / CLK）显示在右下角浮动卡片，点击可展开查看趋势与详情，以便随时监控系统健康度，同时不占用顶部菜单栏空间。

## 3. 需求池（P0 / P1 / P2）

### P0（Must have · 本期必须交付）

- **P0-1 Header 精简**：顶部 Header 首屏元素 ≤5（Logo / 主导航 5 路由 / 单一「菜单」按钮 / 连接状态徽标 / 帮助图标）；移除 CPU、内存、AIT、CLK 时间、三点菜单及全部散落按钮。
- **P0-2 右侧抽屉收纳**：单一「菜单」按钮触发右侧 Drawer，按「视图 / 主题 / 系统 / 调试」分组收纳所有原按钮与快捷入口（含消息引导、调试空间、默认、齿轮、RUNSPACE、主题切换等）。
- **P0-3 右下角浮动状态卡片（StatusFloatingCard）**：折叠态一行小字显示 CPU / 内存 / AIT / CLK；点击展开详情；`fixed` 右下角，不随页面滚动。
- **P0-4 组件复用**：HitlBadge / SessionBadge / BackgroundModeToggle / ThemeToggle / CommandPalette 等全部复用进抽屉或浮动卡片，不重建。

### P1（Should have · 强烈建议本期交付）

- **P1-1 抽屉搜索**：抽屉顶部提供搜索框，模糊匹配分组项 / 功能名，快速定位入口。
- **P1-2 快捷键唤起**：支持 `⌘\`（Ctrl+`\`）快捷开关抽屉。
- **P1-3 浮动卡片折叠 / 隐藏 / 拖动**：可折叠；可隐藏（展开态提供关闭 / 隐藏）；可拖动改变位置（位置记忆持久化）。
- **P1-4 移动端适配**：<768px 下 Header 折叠为汉堡菜单；抽屉全屏或 ≥80% 宽度；浮动卡片可收起为单点。

### P2（Nice to have · 后续迭代）

- **P2-1 状态变化告警**：CPU / 内存超过阈值（默认 85%）时，浮动卡片对应项文字高亮红色并给出提示。
- **P2-2 抽屉自定义布局**：允许用户固定 / 置顶常用分组或入口，形成个人常用区。

## 4. UI / 文案设计稿

### 4.1 新 Header 视觉（默认方案）

```
[灵枢电网 Logo]  监控  灰度  审计  系统   ·   (● 已连接)  [?]  [☰ 菜单]
```

- **左**：LogoHorizontal（灵枢电网 / GridMind）。
- **中**：主导航 5 路由（首页 / /monitor /grayscale /audit /system）。
- **右**：连接状态文字（保留或简化为「● 已连接」）、帮助图标 `?`、单一「菜单」按钮（触发右侧抽屉，主按钮样式）。
- **移除**：CPU / 内存 / AIT / CLK 实时时间、三点菜单、消息引导、调试空间、默认、齿轮、RUNSPACE、主题切换（全部收纳进抽屉）。

### 4.2 右侧抽屉分组（默认方案）

| 分组 | 包含入口 |
|---|---|
| 视图 | 5 路由（/ /monitor /grayscale /audit /system）+ HelpCenter |
| 主题 | BackgroundModeToggle（标准 / 演示）+ ThemeToggle + ColorBlind |
| 系统 | HitlBadge（待审数）+ SessionBadge + ServiceStatus（连接状态） |
| 调试 | 调试空间 + 默认 + 主题变量 |

- 顶部：标题「菜单」+ 关闭按钮；底部：快捷区（消息引导 / RUNSPACE 等原入口）。
- 文案：分组标题统一 2 字名词（视图 / 主题 / 系统 / 调试）；功能名沿用现有文案，不重新造词。
- 宽度默认 360px（见 §5 待确认）。

### 4.3 右下角浮动卡片视觉（默认方案）

- **折叠态**：一行小字 `CPU 38% · 内存 58% · AIT · CLK 11:54:20`，点击展开。
- **展开态**：各项详情 + 最近趋势图（CPU / 内存曲线）+ 最近历史（近 1 小时采样）；右上角提供「隐藏」。
- **样式**：类似 IDE / VS Code 状态条，半透明毛玻璃，`fixed` 右下角（距底 / 距右 16px），不随滚动。
- **交互**：点击展开 / 收起；P1 支持折叠 / 隐藏 / 拖动。

## 5. 待确认问题（默认方案）

1. **Header 保留几个核心元素？** 默认 **5 个**：Logo + 主导航 + 单一「菜单」按钮 + 连接状态徽标 + 帮助图标；连接状态徽标是否合并进抽屉「系统」分组，可再定。
2. **抽屉默认宽度？** 默认 **360px**；是否需要随内容自适应？
3. **浮动卡片默认折叠 / 展开？** 默认**折叠**，点击展开；是否接受首次进入默认展开一次做引导？
4. **浮动卡片位置？** 默认**右下角 fixed**，距底 / 距右各 **16px**；是否需要避开浏览器自带滚动条 / 通知区域？
