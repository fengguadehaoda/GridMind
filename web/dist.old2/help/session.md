# Session 可观测

Header 的 **Session 徽标** 让你随时看到「AI 正在做什么、跑了多久、烧了多少 token、能从哪回滚」。

## 1. 徽标 4 态

| 状态 | 表现 | 含义 |
|---|---|---|
| 空闲 | 灰 / 蓝信息色 | 当前无进行中的会话 |
| 推理中 | 绿色 + 脉冲动画 | AI 正在生成 |
| 已暂停 | 黄色 | 推理被暂停，等待恢复 |
| 运行异常 | 红色 + 抖动 | 推理出错，需介入 |

> 色盲友好：颜色 + 形状 + 图标三重区分，不依赖颜色。

## 2. 点击徽标 → Session 详情抽屉

| 区块 | 内容 |
|---|---|
| 状态 | 4 态徽标 + 运行时长 |
| Token | 累计消耗（估算）；后端未接入时降级为「步骤数 + 耗时」 |
| 步骤时间线 | 每一步：名称 / 节点 / 耗时 / 状态 |
| 可回滚节点 | 历史 checkpoint，各带「回滚到此步」按钮 |

## 3. 回滚

1. 在抽屉「可回滚节点」选择目标步骤；
2. 点击 **回滚到此步**；
3. 二次确认后执行，时间线自动刷新。

```text
确认回滚到步骤「生成候选方案」？
后续步骤将被丢弃，且不可撤销。
```

## 4. Token 说明

当前版本 token 由 SSE `content` 字符数估算（`总字符数 ≈ 估算 token`）。若后端事件流增加数字 `token` 字段，将优先使用精确值；`totalTokens === null` 表示「待接入」，UI 会标注降级原因。

## 5. 常见问题

**Q：空闲状态点击徽标？** 会提示「当前无进行中的会话」。
**Q：回滚后数据丢失？** 回滚会丢弃目标步骤之后的步骤，请在二次确认时留意提示。
